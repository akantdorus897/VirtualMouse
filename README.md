# 🖱️ موس مجازی (Virtual Mouse)

یک اپلیکیشن اندروید که یک **موس مجازی با Touchpad شناور** به گوشی شما اضافه می‌کند.

## امکانات
- ✅ Cursor شناور روی همه‌ی صفحات
- ✅ Touchpad پایین صفحه (مثل touchpad لپ‌تاپ)
- ✅ Tap = کلیک چپ | نگه‌داشتن انگشت = کلیک راست
- ✅ دکمه Drag برای درگ‌کردن (جابه‌جایی آیکون‌ها و اسلایدرها)
- ✅ تنظیم سرعت حرکت موس
- ✅ بدون نیاز به Root

## نصب
1. فایل APK را از بخش **Actions → آخرین Build → Artifacts** دانلود کنید.
2. آن را روی گوشی نصب کنید (اجازه «منابع ناشناس» را بدهید).
3. برنامه را باز کنید، روی «فعال‌کردن Accessibility» بزنید و سرویس **موس مجازی** را روشن کنید.

## ساخت (Build)
هر بار که کد push شود، GitHub Actions به‌صورت خودکار APK می‌سازد.
برای ساخت دستی: تب **Actions → Build APK → Run workflow**.

## محدودیت‌ها
- در صفحه‌های قفل/رمز و اپ‌های بانکی، اندروید اجازه کلیک نمی‌دهد.
- برای APKهای debug حتماً بعد از نصب، آپدیت‌های بعدی را هم از همان مسیر نصب کنید.
