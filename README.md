# 🖱️ موس مجازی (Virtual Mouse) — نسخه ۲

اپ اندروید موس مجازی با Touchpad شناور — بدون نیاز به Root.

## امکانات نسخه ۲
- ✅ نشانگر شناور با ۴ شکل (پیکان، دست، مرکز، دایره) و ۵ رنگ (بنفش، سفید، قرمز، سبز، آبی)
- ✅ تغییر سایز نشانگر (۲۴ تا ۸۰) و سرعت حرکت (۱ تا ۲۰) با SeekBar
- ✅ کلیک چپ (Tap)، کلیک راست، دابل کلیک
- ✅ لمس طولانی روی Touchpad = منوی پاپ‌آپ: کلیک‌ها، اسکرول بالا/پایین، کپی، پیست، انتخاب همه
- ✅ دکمه درگ (Drag & Drop)
- ✅ روشن/خاموش کردن موس از نوتیفیکیشن
- ✅ چک خودکار پرمیشن‌ها (Accessibility و نوتیفیکیشن) در صفحه اصلی

## نصب
1. فایل APK را از **Actions → آخرین Build → Artifacts** دانلود و روی گوشی نصب کنید.
2. در برنامه «فعال‌کردن Accessibility» را بزنید و سرویس «موس مجازی» را روشن کنید.
3. اجازه نوتیفیکیشن را بدهید تا بتوانید از نوار بالا موس را خاموش/روشن کنید.

## ساخت (Build)
هر push به شاخه main باعث build خودکار APK می‌شود (GitHub Actions).
ساخت دستی: تب **Actions → Build APK → Run workflow**.

## محدودیت‌ها
- در صفحه‌های قفل/رمز و اپ‌های بانکی، اندروید اجازه کلیک نمی‌دهد.
- عملیات کپی/پیست روی فیلدهای متنی متمرکز (focused) انجام می‌شود.
